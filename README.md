# 🍺 Pivní Burza — Beer Stock Exchange

A fun, interactive beer price exchange app where prices fluctuate based on orders — just like a real stock market.

**Live demo:** [lucky01dot.github.io/beer-exchange](https://lucky01dot.github.io/beer-exchange/)

---

## How it works

Every time a beer or cocktail is ordered, its price goes **up**. All other drinks go **down** — demand shifts just like on a real exchange. The more popular a drink gets, the more expensive it becomes.

## Features

- 10 items — 6 beers + 4 cocktails
- Live price ticker in the header
- Sparkline charts showing price history
- Market overview table sorted by order volume
- Toast notifications on every order
- Responsive layout for mobile and tablet

## Tech

Plain HTML + CSS + JavaScript. No frameworks, no dependencies, no build step. Single file.
